# Agent guidance

Start at [docs/INDEX.md](docs/INDEX.md), then read [STATE](docs/STATE.md) and only the indexed plan/contracts relevant to the task. [CONTRIBUTING.md](CONTRIBUTING.md) owns the update workflow and persistent integration mode; follow the user's latest instruction.

- Inspect the smallest relevant surface; use targeted searches and avoid rereading entire files.
- Keep scope tight. Reuse valid caches, captures and prior results; avoid full pipelines, builds, paid calls and broad tests unless needed.
- Verify current code and evidence before changing status. Preserve immutable originals/results, canonical identity and last-good data; report unknown or unvalidated results honestly.
- After implementation, update the affected docs and STATE/plan/index in the same change, validate, then integrate according to the current mode.
- Keep progress and final summaries concise. Stop once the requested behavior is sufficiently validated and integrated.
